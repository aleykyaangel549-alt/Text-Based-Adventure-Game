# Text-Based Adventure Game

## About the Project
A simple Java-based text adventure game where players explore
different locations, interact with enemies, and make choices
to progress through the game.

## Technologies Used
- Java
- Object-Oriented Programming
- Eclipse IDE

## Features
- Player movement
- Enemy encounters
- Health system
- Interactive choices
- Game progression

## Project Structure
- Main.java
- Game.java
- Player.java
- Enemy.java

## How to Run
1. Download or clone the repository.
2. Open the project in Eclipse.
3. Run Main.java.
